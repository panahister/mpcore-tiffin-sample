# Visual assets

The Tiffin diagrams are repository-native SVG files generated by `scripts/diagrams/tiffin.py` and its
local drawing kit. Every README diagram has light and dark variants.

`social-preview.svg` is the editable repository-card source and `social-preview.png` is the 1280 × 640
upload-ready GitHub social preview. Tiffin uses the shared cool-spectrum MP visual language while
retaining cyan and teal as its service-platform accents.

Do not add user data, credentials, private design identifiers, or externally hosted dependencies.
